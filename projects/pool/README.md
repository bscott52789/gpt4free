# Pool Project — The Highlands, Chesterfield VA

Working knowledge base for the backyard pool and its equipment pad. Built from a
walk‑around on 2026‑09‑08 (photos, nameplates, breaker panel, and video). The goal is
two‑fold: help the owner understand the system, and give Claude enough context in
future sessions to troubleshoot, size parts, and recommend products without
re‑explaining everything.

**How to use with Claude:** open a session in this repo and say
"read projects/pool and help me with ___". Update `maintenance-log.md` after every
service event so the history stays useful.

## Quick facts

| Item | Value |
|---|---|
| Pool type | In‑ground, rectangular, smooth light‑blue finish. Fiberglass shell if 16 ft wide; an 18 ft width would point to vinyl liner (see `01-pool-structure.md`) |
| Size (owner recollection) | 16x32, 18x32, or 18x36 ft; 3 ft shallow to 6 ft deep, plus 3 entry steps and a tanning ledge |
| Working volume | **~17,500 gal** until measured (range 15,500–19,500 depending on which size is right) |
| Sanitizer | Salt chlorine generator, Pentair iChlor, ideal salt 3600 ppm |
| Heater | Pentair UltraTemp 110 heat pump, 110,000 BTU/hr, built 2026‑04‑18 |
| Pump | Pentair SuperFlo VS, 230 V, 450–3450 rpm |
| Filter | Pentair sand filter with top‑mount clamp‑style multiport valve |
| Electrical | Square D Homeline 12‑space NEMA 3R subpanel at the pad |
| Water temp when documented | ~82 °F (owner reading), air high ~80 °F, low ~60 °F |
